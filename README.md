# Интернет-магазин

Отдельный учебный проект для домашних заданий 14.1, 14.2 и 15.1.

## Установка

Требуется Python 3.9 или новее и Poetry.

```bash
poetry install --with lint,test
poetry run python main.py
```

Пример `main.py` показывает строковое отображение товаров и категории, сложение товаров и перебор товаров категории. Сеттер цены при снижении запрашивает подтверждение: `y` — принять, `n` — отменить.

## Возможности

- `Product`: название, описание, цена, остаток; приватная цена, геттер и сеттер, проверка положительной цены и подтверждение снижения.
- `Product.__str__()`: строка «Название, 80 руб. Остаток: 15 шт.».
- `Product.__add__()`: `a + b` возвращает полную стоимость остатков обоих товаров (`цена × количество` для каждого); сложение с не-`Product` вызывает `TypeError`.
- `Product.new_product()`: создание из словаря; необязательный список для объединения дубликатов по имени с суммированием остатков и выбором максимальной цены.
- `Category`: название, описание, приватный список товаров; общие счётчики категорий и товарных позиций, `add_product()`, строковое представление товаров через `products`.
- `Category.__str__()`: строка «Название, количество продуктов: 200 шт.» — сумма остатков всех товаров категории; геттер `products` строится на `str(product)`.
- `CategoryIterator`: вспомогательный класс для перебора товаров категории в цикле `for` (`__iter__`/`__next__`); `Category.product_list` отдаёт копию списка товаров.
- `load_categories()`: загрузка JSON в объекты категорий и товаров. Пример данных: `data/products.json`.

```bash
poetry run flake8 .
poetry run mypy

```

Отчёт покрытия: `htmlcov/index.html` и `coverage.xml`.

## GitFlow

`main` — основная ветка, `develop` — ветка разработки; задания выполняются в `feature/*` с Pull Request в `develop`. Настройки IDE `.idea/`, виртуальное окружение и временные файлы исключены через `.gitignore`.
